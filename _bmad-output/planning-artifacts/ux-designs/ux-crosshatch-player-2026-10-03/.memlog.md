- (decision) Scope: brand mark for Crosshatch. Roles: (1) logo, (2) default icon for games that supply none, (3) replaces CrossPoint logo where used today, e.g. power-off screen, (4) future website.
- (decision) Concept constraint from user: mark plays off tic-tac-toe, the namesake of Crosshatch.
- (decision) Concept: the mark shows tic-tac-toe either mid-game (game in progress) or a won game. Which of the two is still open.
- (decision) Tone: fun; conveys simple pen-and-paper games.
- (decision) Mark must stand alone (symbol-only usable). Scope expanded: also pick a typeface for the game system and make a wordmark.
- (decision) Relationship to CrossPoint: Crosshatch is a fork, but the logo stands on its own; no sibling look required.
- (decision) Website color version: black crosshatch grid with red and blue X and O. Device version is 1-bit, so X vs O must read without color.
- (decision) Dislikes: none stated.
- (decision) Render both a game-in-progress and a won-game mark; user leans to in-progress.
- (decision) Render both a hand-drawn pen-and-paper treatment and a Phosphor-matched treatment; long-term the mark should match the Phosphor icon set (stroke style, regular/fill weights).
- (decision) Grid is plain tic-tac-toe only; no hatching-technique motif.
- (decision) Typeface: user wants a default text face for the game system but is reluctant to move away from the firmware's built-in font system. Open: where it applies; wordmark layout/casing unanswered.

- (decision) Wordmark typeface: Noto Sans Bold (shipped in firmware, lib/EpdFont/builtinFonts/source/NotoSans/NotoSans-Bold.ttf). Serif dropped. Still open: 'Player' sizing on the stack (same size vs 60%), lock-screen name (Crosshatch vs Crosshatch / Player), website colours, whether Noto Sans is also the game-system default text face.
- (decision) Stacked lockup: 'Player' at the smaller (~60%) size. User concern: red and blue together may vibrate (chromostereopsis); researching, may change the website colour direction.
- (assumption) Colour research: chromostereopsis/vibration is strongest for saturated red+blue, near-equal luminance, adjacent, on dark backgrounds. Drafted #E5322D / #2B6CFF have relative luminance 0.191 vs 0.185 (contrast 1.03:1) = equiluminant, the risk condition. In the mark they never touch (grid between), but they sit side by side on the near-black tile. Mitigations from sources: change lightness of one, reduce saturation, separate with neutral/outline. Colours remain undecided; user open to a different direction.
