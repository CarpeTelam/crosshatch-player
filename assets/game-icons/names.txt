# The game icon library's name map: scripts/gen_game_icons.py reads it and writes
# lib/GameIcons/GameIcons.generated.h.
#
# Source: the Phosphor icon set, npm package @phosphor-icons/core, version 2.1.1
#   https://registry.npmjs.org/@phosphor-icons/core/-/core-2.1.1.tgz
#   sha256 313332be6190b724da24107addd781799b48bf76b13963f24501112ffe1baadd
# Licence: MIT, phosphor/LICENSE (copied from the package). The SVGs under
# phosphor/ are the package's assets/regular/ and assets/fill/ files, byte for byte.
# The library holds Phosphor icons only.
#
# Every name is Phosphor's own: the SVG's file stem, hyphens included, without
# "-fill". Only the names listed here are in the library; https://phosphoricons.com
# previews an icon's drawing, and a Phosphor icon not listed here does not exist
# for games. Every name ships in both weights, regular and fill.
#
# The names are part of the game API level: games call ch.gfx.icon by them, and
# docs/crosshatch/api-level-<n>.txt lists each one as `icon <name>`. Never rename
# or remove one in a frozen level.
#
# Two lines per name, regular then fill, whitespace-separated:
#   <name> regular phosphor/regular/<name>.svg
#   <name> fill phosphor/fill/<name>-fill.svg
# A name is [a-z][a-z0-9-]{0,31} without "--", not ending in "-" or "-fill".
# docs/crosshatch/game-icons.md lists every icon with its reason.
